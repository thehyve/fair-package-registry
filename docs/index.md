# FAIR Package Registry PoC

This project is a Proof of Concept for the FAIR Package Registry, developed by the Dutch Health Care Institute (Zorginstituut Nederland) and The Hyve. It provides ontologies, taxonomies, and example data for FAIR Package Statements in healthcare.

- [GitHub Project Root](https://github.com/thehyve/fair-package-registry) — View the source code, scripts, and documentation on GitHub.
- [Ontology Documentation](https://thehyve.github.io/fair-package-registry/ontology.html) — Documentation for the FAIR Package Registry ontology.
- [Taxonomy Documentation](https://thehyve.github.io/fair-package-registry/taxonomy-complete.html) — Documentation for the complete taxonomy.

See the [README](https://github.com/thehyve/fair-package-registry) for more details.
